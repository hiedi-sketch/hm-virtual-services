Create a “Client Checklist” button on the Client Details page.

When clicked, it should open an editable onboarding checklist for that specific client.

The checklist should have these columns:

* Stage
* Task
* Who
* Status
* Notes
* Due Date

The user should be able to:

* Edit any checklist item
* Delete checklist items that do not apply
* Add custom checklist items
* Change the status
* Filter by Stage, Who, and Status
* See overall onboarding progress as a percentage
* Mark onboarding as complete once all required items are done

Status dropdown options:

* Not Started
* Waiting on Client
* Waiting on Hiedi
* In Progress
* Complete
* Not Applicable

Who dropdown options:

* Hiedi
* Client
