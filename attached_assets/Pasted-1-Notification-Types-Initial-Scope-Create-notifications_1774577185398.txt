1. Notification Types (Initial Scope)

Create notifications for:

New message received
New task assigned
New comment on task
Invoice sent
Invoice reminder (due / overdue)
2. Notification Data Model

Create a notifications table:

id
userId (or clientId for portal users)
type (message, task, invoice, etc.)
title (short message)
description (optional detail)
relatedId (taskId, messageId, invoiceId, etc.)
isRead (boolean)
createdAt
3. Trigger Notifications (CRITICAL)

Automatically create a notification when:

Messages
When a new message is sent:
Notify the recipient user/client
Tasks
When a task is assigned to a user/client
When a comment is added to a task
Invoices
When invoice is sent
When reminder is triggered

Show unread count badge
Dropdown Behavior

Show:
Title
Time (e.g., “2 hours ago”)

Mark as read

“Mark all as read” option

Full list of notifications
